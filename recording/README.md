# Voice recordings

Upload each batch zip from the recording page (https://sajilonepali.app/studio) here, for example
`sajilo-voice-batch-1.zip`. If you upload a batch again with more lines, keep the same name so the new one replaces the old.

This folder is not part of the website: only the cleaned-up clips in `public/audio/` are published, after
`python3 scripts/install_my_voice.py recording/sajilo-voice-batch-1.zip`.
Step by step guide: `docs/my-voice/HOW-TO-RECORD.md`.
