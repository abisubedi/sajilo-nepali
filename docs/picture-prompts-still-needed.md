# Picture prompts: Nepali money for the number cards

For the 9 number cards in First Steps, Lesson 3 (बजार र किनमेल), written 26 Nov 2026. Each picture shows Nepali money with the Devanagari numeral, so the card teaches the digit and the money together.
Attach `art/pandu-namaste.png` as the style reference. Save each picture into `art/` with the file name shown (for example `art/w-one-1.png`).

Tip: if the image tool writes the numeral wrongly, ask it again or fix the digit; the numerals must read १, २, ५, १०, २०, ५०, १००, ५०० and १०००.
