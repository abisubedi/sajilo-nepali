# Sajilo Nepali: picture prompts

Every picture in the game, 393 in total. Each prompt below is complete (it already includes the shared style), so you can paste it as is.

## How to make them match

1. **Same tool, same settings** for everything. Square images unless the size column says otherwise.
2. **Make section 1 (the cast) and `pandu-wave` first.** Then attach the matching cast picture as a reference whenever a prompt mentions that person (Maya, Arjun, Aama, Hajuraama…), so they look the same in every picture.
3. **Transparent background** (PNG). If your tool can't do it, use plain white and I'll remove it. Exception: `app-icon` and `og-image` need a full background.
4. **Keep the file names.** Put the images in `public/img/` in the repo, or send them to me in batches. I'll shrink them for the web and swap them in.
5. **No words in pictures.** Image tools misspell Nepali, so any Nepali letters (like **अ** on the Letter Master sticker) are added by the app.
6. **Priority if you want to do it in stages:** Pandu → avatars → stickers → word pictures → lesson icons → game icons → sentence scenes (optional).

## Shared style (already inside every prompt)

> Cute children's game illustration, flat vector style with soft shading, thick rounded dark-navy outlines, people and animals have big friendly eyes while objects and food stay simple without faces, simple clear shapes, bright cheerful colors (crimson red #e2453c, royal blue #2f6fd6, leaf green #2fa75a, marigold yellow #f6b71c, warm orange #e8742a), Nepali cultural setting, one clear subject centered with empty space around it, isolated on a transparent background, no text, no letters, no numbers, no watermark, suitable for kids aged 4–15.
