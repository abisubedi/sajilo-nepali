# Sajilo Nepali: recording script

Every clip in the game, 487 in total, numbered in the order they appear.

## How to record

1. **One recording per section** is easiest. Read the lines in order and **pause about 1 second** between lines. Start each section by saying nothing for 1 second.
2. If you slip, pause, then **say the line again**. Tell me the number and I'll use the second take.
3. Quiet room, phone or mic about a hand's width from your mouth, the same place and volume each time.
4. Lines marked **(polite)** are timi-form commands: say the final "a" (utha, not uth).
5. Save as mp3 (m4a or wav also fine) and name each file by its section number, like `section-01.mp3`, `section-02.mp3`. Single re-takes can be named by line number, like `137.mp3`.
6. Upload to a **voice** folder in the repo on GitHub and commit, then tell me which sections are done.
